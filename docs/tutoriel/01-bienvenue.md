# Chapitre 1 · Bienvenue dans ton aventure Next.js ✨

Bonjour, petit·e aventurier·ère du web ! Dans ce cours, nous allons explorer ensemble un projet Next.js appelé **Feedback Data Management**. Imagine que nous construisons une cabane numérique où les gens peuvent ranger leurs comptes, leurs fruits magiques (oui oui 🍓) et leurs transactions d'argent.

## Qu'est-ce que Next.js ?
Next.js est comme une grande boîte à outils pour fabriquer des sites web très rapides. Elle est construite avec React, un langage qui permet de créer des éléments que tu vois sur une page (boutons, textes, images…). Next.js nous aide à organiser tout cela facilement.

## Ce que tu vas apprendre
- Comment démarrer le projet sur ton ordinateur.
- Comment les dossiers sont rangés.
- Quels super pouvoirs donnent les fichiers importants.
- Comment les données sont récupérées et affichées à l'écran.
- Comment fonctionnent les formulaires et les graphiques.

## Comment lire ce cours
Chaque chapitre est dans un fichier séparé. Lis-les dans l'ordre (1, 2, 3…) comme un livre. À chaque fois, nous regarderons du code et nous l'expliquerons avec des mots simples. Tu peux suivre en même temps dans le projet en ouvrant les fichiers mentionnés.

Prêt·e à commencer ? Allons-y doucement et avec le sourire ! 😄
